Импорт модулей в Excel VBA для MAC
================================

Excel 16.59 для Mac: File -> Import File не декодирует русский
в MsgBox и StatusBar.

Откройте файл в Cursor из VBA_Import_Windows и вставьте
код ниже Attribute / VERSION в модуль (буфер Unicode).

Папка VBA_Import тоже UTF-8 без BOM, тот же текст.
Не используйте File -> Import File для .bas на Mac —
русский в сообщениях снова станет кракозябрами.

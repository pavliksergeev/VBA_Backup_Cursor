# docs

Документы проекта «Расчет ЭХЗ ПТМ» 3.0: описания, инструкции, заметки.

Исходники VBA — в `VBA_Import_Windows/` (канон для вставки на Mac) и зеркало `VBA_Import/`.
Книга Excel — `PTM_ECP_Calculator_3.0.xlsm`.
Актуальные руководства (2026-09-29):
- `Руководство программиста Расчет ЭХЗ ПТМ (Excel VBA).docx`
- `Руководство пользователя Расчет ЭХЗ ПТМ (Excel VBA).docx`
- `Методика приемосдаточных испытаний программы расчетов анодных заземлителей по СТО Газпром 9.2-003-2020.docx` — приёмка 3.0, исходные RunAllTests
- `Приложение 1. Информационный лист Прогамма расчета ЭХЗ.docx` — информационный лист 3.0
- `Приложение 2 — Опросный лист, исходные данные проекта ЭХЗ.xltx` — опросный лист исходных данных 3.0
- `Приложение 3 - Результаты расчета анодных заземлителей ЭХЗ.xltx` — пример результатов расчёта АЗ 3.0
